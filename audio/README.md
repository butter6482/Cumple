# Música

Coloca aquí el archivo de audio autorizado con el nombre `audio/i-see-the-light.mp3`
(o cambia `music.src` en `config.js`).

- Los `.mp3` de esta carpeta están en `.gitignore`: la canción tiene derechos de autor y no debe subirse a un repositorio público.
- Si el archivo no existe, la página funciona igual, solo que sin música.
